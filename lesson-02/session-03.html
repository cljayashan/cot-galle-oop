1. The Flowchart (You Already Know This)

Figure 3.1 — Standard algorithm: input dimensions, multiply, output area.

2. Version A — Procedural Java

Data (length, width) lives as separate variables. The formula is in main.

import java.util.Scanner;

public class Main
{
    public static void main(String[] args)
    {
        Scanner scanner = new Scanner(System.in);

        // INPUT — like the INPUT parallelogram
        System.out.print("Enter length: ");
        double length = Double.parseDouble(scanner.nextLine());

        System.out.print("Enter width: ");
        double width = Double.parseDouble(scanner.nextLine());

        // PROCESS — like the PROCESS rectangle
        double area = length * width;

        // OUTPUT — like the OUTPUT parallelogram
        System.out.println("Area = " + area);
    }
}
Beginner's Logic Breakdown
  • double — decimal number type (length can be 5.5)
  • Scanner / nextLine() — waits for user to type and press Enter (INPUT)
  • Double.parseDouble(...) — converts text "5.5" into number 5.5
  • area = length * width — same formula as flowchart PROCESS

3. Version B — Object-Oriented Java

Now the rectangle knows its own dimensions and calculates its own area. Data and behaviour live together.

import java.util.Scanner;

// Blueprint — describes what every rectangle has and can do
class Rectangle
{
    // Fields — data (attributes)
    public double length;
    public double width;

    // Method — behaviour
    public double getArea()
    {
        return length * width;
    }
}

public class Main
{
    public static void main(String[] args)
    {
        Scanner scanner = new Scanner(System.in);

        // Create an object from the blueprint
        Rectangle rect = new Rectangle();

        System.out.print("Enter length: ");
        rect.length = Double.parseDouble(scanner.nextLine());

        System.out.print("Enter width: ");
        rect.width = Double.parseDouble(scanner.nextLine());

        System.out.println("Area = " + rect.getArea());
    }
}
Figure 3.2 — Same result, different organisation. OOP prepares you for many rectangles, not just one calculation.
Key Terms

Class = blueprint (Rectangle). Object = one real instance (rect). new Rectangle() builds the object in memory. dot notation (rect.length) accesses members.
