1. VS Code — Your IDE

An IDE (Integrated Development Environment) combines editor, compiler, and debugger. We use VS Code with the Extension Pack for Java (free). Only VS Code is allowed for this module.

Setup Steps
  1. Download VS Code from https://code.visualstudio.com/
  2. Install a JDK 17+ (Temurin/Adoptium) if one is not already on the lab PCs
  3. In VS Code: Extensions (Ctrl + Shift + X) → install Extension Pack for Java by Microsoft
  4. Create a folder named HelloOop, then File → Open Folder... and select it
  5. In Explorer, create Main.java (and optional package folders as needed)

2. Anatomy of Every Java Program

Every console program you write in this module follows the same skeleton:

// 1. PACKAGE — groups related classes (like a folder for code)
package hellooop;

// 2. CLASS — blueprint; file name must match the public class name
public class Main
{
    // 3. MAIN — entry point; the JVM starts here
    public static void main(String[] args)
    {
        // 4. STATEMENTS — instructions executed top to bottom
        System.out.println("Hello, Object Oriented World!");
    }
}
Figure 2.2 — Nesting: package contains class contains main contains your statements.
Beginner's Logic Breakdown — main()

Think of main as the START oval in a flowchart. The computer finds main, runs each line inside the { } braces in order, then stops. System.out.println is like an OUTPUT parallelogram — it displays text on screen. The semicolon ; ends each instruction (like a full stop in English).

2.1 What Each Keyword Means

import java.util.Scanner;Import tools (Scanner, etc.) when neededInclude standard library symbols

3. JShell — Try One Line at a Time

In VS Code open the Terminal (View → Terminal) and run jshell (comes with the JDK). Type:

jshell> 2 + 3
$1 ==> 5
jshell> System.out.println("Quick test");
Quick test
Tip

Use jshell to test syntax before putting it in main(). Great when you forget how something works.
