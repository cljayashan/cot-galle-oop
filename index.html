How These Notes Are Organised

Students know flowcharts but start Java from scratch. Content is in four blocks, delivered as 32 sequenced sessions (alternating 3-hour and 2-hour slots). Start from the Sessions hub.

  • Block 0: Beginner Java — Hello World to methods
  • Block 1: Paradigm shift — procedural vs OOP
  • Block 2: Core OOP + Library System project
  • Block 3: Relationships + School project + revision

Every section includes Beginner's Logic Breakdown, commented Java code, SVG diagrams, and a Lab Task.
