1. Method Overloading — One Name, Many Versions

Definition — Method Overloading

Method overloading means defining several methods in the same class with the same name but different parameter lists (different number, types, or order of parameters). The compiler selects the correct version by matching the arguments at the call site. This is compile-time polymorphism.

You have already used overloading: System.out.println is overloaded for String, int, double, and more — each is a different overload of one method name.

class Calculator
{
    // Overload 1: two ints
    public int add(int a, int b)
    {
        return a + b;
    }

    // Overload 2: three ints — different COUNT
    public int add(int a, int b, int c)
    {
        return a + b + c;
    }

    // Overload 3: two doubles — different TYPES
    public double add(double a, double b)
    {
        return a + b;
    }

    // Overload 4: String + int — different types and meaning
    public String add(String text, int number)
    {
        return text + number;    // "Room" + 5 → "Room5"
    }

    // ILLEGAL — only return type differs from Overload 1:
    // public double add(int a, int b) { return a + b; }
    // Error: already defines 'Add' with the same parameter types
}

Calculator calc = new Calculator();
System.out.println(calc.add(2, 3));          // → Overload 1 → 5
System.out.println(calc.add(2, 3, 4));       // → Overload 2 → 9
System.out.println(calc.add(2.5, 3.5));      // → Overload 3 → 6.0
System.out.println(calc.add("Room", 5));     // → Overload 4 → Room5

1.1 Overloading Rules

RuleValid?Example
Different parameter count✓ Yesadd(int, int) vs Add(int, int, int)
Different parameter types✓ Yesadd(int, int) vs add(double, double)
Different parameter order✓ Yesprint(int, String) vs print(String, int)
Different return type only✗ Noint Get() vs double Get() — compiler cannot choose from the call alone
Only parameter names differ✗ NoNot a distinct overload in Java
Figure 11.1 — The compiler routes each call to exactly one overload by comparing argument types and count against every candidate signature.
🧠 Beginner's Logic Breakdown
  1. Receptionist analogy: four staff members all named "Add" sit at different desks. The receptionist (compiler) reads what the visitor carries — two ints go to desk 1, three ints to desk 2. Routing is decided when the code compiles, not when it runs.
  2. Why return type fails: in calc.add(2, 3) nothing tells the compiler whether you want an int or double back. Only the parameter list can distinguish overloads.
  3. Overload when meanings match: Search, Print, Add — same operation, different inputs. Use separate names when operations differ in purpose.

2. Constructor Overloading & Chaining with this

Multiple constructors in one class follow the same overloading rules as methods. The class name is the method name; Java picks the constructor whose parameter list matches the new arguments.

class Book
{
    private String title;
    public String getTitle() { return title; }
    public void setTitle(String title) { this.title = title; }
    private String author;
    public String getAuthor() { return author; }
    public void setAuthor(String author) { this.author = author; }
    private String isbn;
    public String getIsbn() { return isbn; }
    // no public setter — write only inside this class
    private int yearPublished;
    public int getYearPublished() { return yearPublished; }
    public void setYearPublished(int yearPublished) { this.yearPublished = yearPublished; }
    private boolean isAvailable;
    public boolean isAvailable() { return isAvailable; }
    // no public setter — write only inside this class

    // Primary constructor — all required data
    public Book(String title, String author, String isbn, int yearPublished)
    {
        this.title = title;
        this.author = author;
        this.isbn = isbn;
        this.yearPublished = yearPublished;
        isAvailable = true;
    }

    // Overloaded constructor — year unknown; chains to primary with year = 0
    public Book(String title, String author, String isbn) {
        this(title, author, isbn, 0);
        // Body runs AFTER the chained constructor finishes.
        // Year 0 conventionally means "unknown publication year".
    }
}

Book b1 = new Book("Clean Code", "Robert C. Martin", "978-0132350884", 2008);
Book b2 = new Book("Head First Java", "Andrew Stellman", "978-1491976708");  // overload 2

2.2 this — Two Uses Recap

UseSyntaxPurpose
Name resolutionthis.name = name;Distinguish field from parameter with the same identifier
Constructor chainingpublic Student(String n) { this(n, 18); }One constructor calls another; avoids duplicate assignment logic
 
class Student
{
    private String name;
    private int age;

    public Student(String name, int age)
    {
        this.name = name;     // Use 1: name resolution
        this.age = age;
    }

    public Student(String name)
    {
        this(name, 18);   // Use 2: chaining — default age 18
    }

    public Student()
    {
        this("Unnamed", 18);   // chains through the one-param constructor
    }
}
Chaining Rule

this(...) must be the first statement in the constructor body and must call another constructor in the same class. The chained constructor runs completely before any remaining statements in the current constructor.

2.2 Member.java — Full Implementation

// File: Member.java

    class Member
    {
        private String name;
        public String getName() { return name; }
        public void setName(String name) { this.name = name; }
        private String membershipNumber;
        public String getMembershipNumber() { return membershipNumber; }
        // no public setter — write only inside this class
        private int booksBorrowed;
        public int getBooksBorrowed() { return booksBorrowed; }
        // no public setter — write only inside this class

        public Member(String name, String membershipNumber)
        {
            this.name = name;
            this.membershipNumber = membershipNumber;
            this.booksBorrowed = 0;
        }

        public void borrowBook()
        {
            booksBorrowed++;
        }

        public void returnBook()
        {
            if (booksBorrowed > 0) booksBorrowed--;
        }

        public void printDetails()
        {
            System.out.println("  [" + membershipNumber + "] " + name + " — " + booksBorrowed + " book(s) out");
        }

        // DELETE setMembershipNumber() — constructor sets it once, correctly.
    }
🧠 Beginner's Logic Breakdown
  1. Why delete setIsbn? It was a teaching bridge in Phase 2. Constructors set read-only data at birth — a separate setter would re-open the security hole encapsulation closed.
  2. Chaining for unknown year: yearPublished = 0 is a convention meaning "not recorded". printDetails displays "Unknown" instead of 0.
  3. Membership numbers are permanent: like ISBN, they are set once in the constructor with public getter / no public setter.

3. Step 2 — Library Class with Overloaded Find

Move the catalog out of Main.java into a Library class. Searching belongs with the data it searches — this is a preview of good class design.

import java.util.ArrayList;
import java.util.List;

// File: Library.java

    class Library
    {
        private List<Book> catalog = new ArrayList<>();
        private List<Member> members = new ArrayList<>();

        public void addBook(Book book)   { catalog.add(book); }
        public void AddMember(Member m)  { members.add(m); }

        // ---- OVERLOADED FIND METHODS ----

        // Overload 1: search by title (case-insensitive)
        public Book find(String title)
        {
            for (Book b : catalog)
            {
                if (b.getTitle().equalsIgnoreCase(title))
                    return b;
            }
            return null;
        }

        // Overload 2: search by author AND year — different parameter list
        public Book find(String author, int year)
        {
            for (Book b : catalog)
            {
                if (b.getAuthor().equalsIgnoreCase(author)
                    && b.getYearPublished() == year)
                    return b;
            }
            return null;
        }

        // ISBN search — separate name because Find(String) already uses one String
        // (title and ISBN would have identical signatures — compiler cannot tell them apart)
        public Book findByIsbn(String isbn)
        {
            for (Book b : catalog)
            {
                if (b.getIsbn().equals(isbn))
                    return b;
            }
            return null;
        }

        public void listAllBooks()
        {
            System.out.println("--- Catalog (" + catalog.size() + " books) ---");
            for (Book b : catalog) b.printDetails();
        }

        public void listAllMembers()
        {
            System.out.println("--- Members (" + members.size() + ") ---");
            for (Member m : members) m.printDetails();
        }
    }
Figure 12.2 — Search routing: two-parameter Find handles author+year; ISBN uses findByIsbn because Find(string) is already taken by title search.

4. Step 3 — Menu Integration in Main.java

import java.util.Scanner;

// File: Main.java (key excerpts — adapt your existing menu)

    public class Main
    {
        static Library lib = new Library();

        public static void main(String[] args)
        {
        Scanner scanner = new Scanner(System.in);
            // Seed data — one line per object
            lib.addBook(new Book("Clean Code", "Robert C. Martin", "978-0132350884", 2008));
            lib.addBook(new Book("The Pragmatic Programmer", "Hunt & Thomas", "978-0201616224", 1999));
            lib.addBook(new Book("Head First Java", "Andrew Stellman", "978-1491976708"));
            lib.AddMember(new Member("Kasun Perera", "MEM-001"));
            lib.AddMember(new Member("Nadee Silva", "MEM-002"));

            boolean running = true;
            while (running)
            {
                System.out.println("\n=== Library System (Phase 3) ===");
                System.out.println("1. List all books");
                System.out.println("2. Search by title");
                System.out.println("3. Search by author + year");
                System.out.println("4. Search by ISBN");
                System.out.println("5. Add new book");
                System.out.println("6. List members");
                System.out.println("0. Exit");
                System.out.print("Choice: ");
                String choice = scanner.nextLine();

                switch (choice)
                {
                    case "1": lib.listAllBooks(); break;
                    case "2": SearchByTitle(); break;
                    case "3": SearchByAuthorYear(); break;
                    case "4": SearchByIsbn(); break;
                    case "5": AddNewBook(); break;
                    case "6": lib.listAllMembers(); break;
                    case "0": running = false; break;
                    default: System.out.println("Invalid choice."); break;
                }
            }
        }

        static void SearchByTitle()
        {
            System.out.print("Enter title: ");
            String title = scanner.nextLine();
            Book found = lib.find(title);          // Overload 1
            if (found != null) found.printDetails();
            else System.out.println("Book not found.");
        }

        static void SearchByAuthorYear()
        {
            System.out.print("Enter author: ");
            String author = scanner.nextLine();
            System.out.print("Enter year: ");
            int year = Integer.parseInt(scanner.nextLine());
            Book found = lib.find(author, year);   // Overload 2
            if (found != null) found.printDetails();
            else System.out.println("Book not found.");
        }

        static void SearchByIsbn()
        {
            System.out.print("Enter ISBN: ");
            String isbn = scanner.nextLine();
            Book found = lib.findByIsbn(isbn);
            if (found != null) found.printDetails();
            else System.out.println("Book not found.");
        }

        static void AddNewBook()
        {
            System.out.print("Title: ");  String title = scanner.nextLine();
            System.out.print("Author: "); String author = scanner.nextLine();
            System.out.print("ISBN: ");   String isbn = scanner.nextLine();
            System.out.print("Year (0 if unknown): ");
            int year = Integer.parseInt(scanner.nextLine());
            lib.addBook(new Book(title, author, isbn, year));
            System.out.println("Book added.");
        }
    }
