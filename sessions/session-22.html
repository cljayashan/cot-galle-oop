1. The Project Brief

The Client's Request — School System

"We manage a small school. Teachers are assigned to Classrooms (one classroom each; classrooms have at most one teacher). Students enrol into classrooms and sometimes transfer between them. Each classroom was built with a fixed set of Desks (Session 23). We need to assign, transfer, and print a full school summary."

Relationship analysis before any code — this is the discipline of Block 3:

PairPhrase in the BriefRelationshipWhy
Teacher – Classroom"assigned to"AssociationBoth exist independently; the link can change any term
Classroom – Student"enrol… transfer"AggregationStudents exist before/after; move between rooms
Classroom – Desk"built with a fixed set"Composition (Session 23)Desks created with the room, destroyed with classroom
School – Classroom"we manage"Composition (Session 23)Rooms are built inside the school
