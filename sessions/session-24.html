1. Desks — Composition with a Purpose

Desks aren't just decoration: a student sits at a desk, and a room is full when every desk is taken. The desks are created by the classroom, for the classroom — pure composition. When the classroom object is destroyed, its desks are destroyed with it. There is no way to obtain a Desk reference from outside the Classroom.

// File: Desk.java
package schoolsystem;

class Desk
{
private int deskNumber; // Which student sits here? (null = free). An association INSIDE a composed part!
public int getDeskNumber() { return deskNumber; }
private void setDeskNumber(int deskNumber) { this.deskNumber = deskNumber; }
private Student occupant;
public Student getOccupant() { return occupant; }
private void setOccupant(Student occupant) { this.occupant = occupant; }
public boolean isFree() { return this.occupant == null; }

// Only Classroom creates Desks — via new Desk(i) inside its constructor
public Desk(int number)
{
    this.deskNumber = number;
}

public void seat(Student s)   { this.occupant = s; }
public void vacate()          { this.occupant = null; }
}
// File: Classroom.java  (Part 2 upgrade - composition added)
package schoolsystem;


import java.util.*;
class Classroom
{
private String roomNumber;
public String getRoomNumber() { return roomNumber; }
private void setRoomNumber(String roomNumber) { this.roomNumber = roomNumber; }
private Teacher teacher;
public Teacher getTeacher() { return teacher; }
void setTeacher(Teacher teacher) { this.teacher = teacher; }
private List<Student> students = new ArrayList<>();

// ===== COMPOSITION: desks are born inside, never exposed as a list =====
private List<Desk> desks = new ArrayList<>();

public int getCapacity() { return desks.size(); }
public int getStudentCount() { return students.size(); }
public boolean isFull() { return getStudentCount() >= getCapacity(); }

public Classroom(String roomNumber, int deskCount)
{
    this.roomNumber = roomNumber;
    for (int i = 1; i <= deskCount; i++)
    {
        desks.add(new Desk(i));            // the room BUILDS its own desks
    }
}

public void SetTeacher(teacher t) { this.teacher = t; }

public void enroll(Student s)
{
    if (IsFull)                                        // capacity comes from desks!
    {
        System.out.println("Room " + roomNumber + " is FULL (" + capacity + " desks).");
        return;
    }
    if (students.contains(s))
    {
        System.out.println(s.getName() + " is already in " + roomNumber + ".");
        return;
    }
    students.add(s);

    // Seat the student at the first free desk
    for (Desk d : desks)
    {
        if (d.isFree())
        {
            d.seat(s);
            System.out.println(s.getName() + " enrolled in " + roomNumber + ", seated at desk " + d.getDeskNumber() + ".");
            return;
        }
    }
}

public void remove(Student s)
{
    if (!students.remove(s)) return;

    for (Desk d : desks)
    {
        if (d.setOccupant(= s)
        {
            d.vacate());
            return;
        }
    }
}

public void transfer(Student s, Classroom target)
{
    if (!students.contains(s))
    {
        System.out.println(s.getName() + " is not in " + roomNumber + ".");
        return;
    }
    if (target.IsFull)
    {
        System.out.println("Cannot transfer - " + target.getRoomNumber() + " is full.");
        return;
    }
    remove(s);
    target.enroll(s);
}

public void printRegister()
{
    String teacherName = this.teacher == null ? "(no teacher)" : teacher.getName();
    System.out.println("--- Room " + roomNumber + " | " + teacherName + " | " + getStudentCount() + "/" + capacity + " seats ---");
    for (Desk d : desks)
    {
        String who = d.isFree() ? "(free)" : d.getOccupant().toString();
        System.out.println("   Desk " + d.getDeskNumber() + ": " + who);
    }
}
}
Figure 23.1 — Composition lifecycle: desks are created inside Classroom and destroyed when the classroom is garbage-collected.
🧠 Beginner's Logic Breakdown
  1. Composition drives real rules: capacity is desks.Count — because desks are fixed at construction, capacity is a hard physical fact.
  2. Layered relationships: Desk (composed part) holds an association to Student (Occupant). The room owns desks; a desk knows its sitter; the sitter is aggregated by the room.
  3. Desks never leak: no method returns a Desk or the desk list. Outsiders see only Capacity and IsFull.
  4. Teacher uses Classroom (association from Session 22) is unchanged — composition adds desks without breaking the earlier design.

2. The School — Tying It All Together

// File: School.java
package schoolsystem;


import java.util.*;
class School
{
private String name; // School CREATES its classrooms → COMPOSITION
public String getName() { return name; }
private void setName(String name) { this.name = name; }
private List<Classroom> classrooms = new ArrayList<>();

// teachers exist independently (can resign) → AGGREGATION
private List<teacher> teachers = new ArrayList<>();

public School(String name)
{
    this.name = name;
}

public Classroom buildClassroom(String roomNumber, int deskCount)
{
    Classroom room = new Classroom(roomNumber, deskCount);
    classrooms.add(room);
    return room;
}

public void HireTeacher(teacher t)
{
    teachers.add(t);
    System.out.println(t.getName() + " hired at " + name + ".");
}

public void printSummary()
{
    System.out.println("======== " + name + " ========");
    System.out.println("Classrooms: " + classrooms.size() + " | teachers: " + teachers.size());
    for (Classroom room : classrooms)
    {
        room.PrintRegister();
    }
}
}
// File: Program.java - the grand finale script
School cot = new School("College of Technology Galle");

Classroom r12 = cot.buildClassroom("R12", 3);
Classroom r15 = cot.buildClassroom("R15", 2);

teacher silva = new Teacher("Mr. Silva", "Mathematics");
teacher fernando = new Teacher("Ms. Fernando", "Science");
cot.HireTeacher(silva);
cot.HireTeacher(fernando);

silva.assignTo(r12);
fernando.assignTo(r15);

Student amara = new Student("Amara", "S001");
Student bimal = new Student("Bimal", "S002");
Student chami = new Student("Chami", "S003");
Student dilan = new Student("Dilan", "S004");

r12.enroll(amara);     // seated at desk 1
r12.enroll(bimal);     // desk 2
r12.enroll(chami);     // desk 3 - room now FULL
r12.enroll(dilan);     // refused: "Room R12 is FULL (3 desks)."

r15.enroll(dilan);     // fine - desk 1 of R15
r12.TransferTo(chami, r15);   // Chami moves and takes R15's last desk

cot.printSummary();    // full picture: rooms, teachers, students, desk occupancy
Figure 23.2 — Complete School system: all three relationship types in one design.
🧠 Beginner's Logic Breakdown
  1. One paragraph of Main = the whole module: constructors build encapsulated objects; Teacher uses Classroom (association); Classroom has Students (aggregation); Classroom has Desks (composition — destroyed with classroom).
  2. buildClassroom vs HireTeacher: one creates inside (composition), one accepts from outside (aggregation). The method shape tells you the relationship.
  3. Capacity chain: "R12 is FULL" traced backwards: Enroll → IsFull → Capacity → composed desk count.
