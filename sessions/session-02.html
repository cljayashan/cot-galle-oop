1. Variables and Data Types — Giving the Computer a Memory

In your flowcharts you wrote things like area = length × width without worrying about what "length" was. In Java, every piece of data must be stored in a variable, and every variable must have a declared data type that tells the computer what kind of data it holds and how much memory to reserve.

Definition — Variable

A variable is a named storage location in memory that holds a value which may change while the program runs. In Java, declaring a variable follows the pattern: type name = value; — for example int age = 25;

Definition — Data Type

A data type defines what kind of value a variable can hold. Java is strongly typed — you cannot put text into a number variable without converting it first. Choosing the right type prevents errors and uses memory efficiently.

Java TypeStoresExample DeclarationTypical Use
intWhole numbers (no decimals)int age = 25;Counting, IDs, quantities
doubleDecimal numbersdouble price = 149.99;Measurements, averages, temperatures
StringText (0 or more characters)String name = "Kasun";Names, addresses, messages
booleantrue or false onlyboolean isPassed = true;Yes/no flags, conditions
charExactly one characterchar grade = 'A';Grades, single symbols (single quotes!)

1.1 Declaring and Using Variables

// Declare (create) a variable and give it an initial value
int studentCount = 30;
double averageMark = 72.5;
String courseName = "OOP";
boolean isEnrolled = true;
char grade = 'B';
double fee = 15000.00;          // use double for money in this module

// Change a variable's value later
studentCount = 31;          // the old value (30) is replaced
averageMark = averageMark + 2.5;  // can use the variable in calculations
Quote Rules
  • String values use double quotes: "Hello"
  • char values use single quotes: 'A'
  • For money in this module we use double: 99.99
  • boolean values are just the words true or false (no quotes)

2. Console Input and Output

At the top of any program that reads the keyboard, add:

import java.util.Scanner;
// inside main:
Scanner sc = new Scanner(System.in);

2.1 Output — Displaying Text

MethodBehaviourExample
System.out.println(...)Print text and move to the next lineSystem.out.println("Hello");
System.out.print(...)Print text but stay on the same lineSystem.out.print("Name: ");

Use System.out.print for prompts (cursor stays on the same line) and System.out.println for results and headings.

2.2 Input — Reading from the Keyboard

sc.nextLine() waits for the user to type something and press Enter. It always returns a String — even if the user types digits.

import java.util.Scanner;
Scanner sc = new Scanner(System.in);

System.out.print("Enter your age: ");     // prompt — cursor stays on same line
String input = sc.nextLine();   // reads whatever the user typed as TEXT
// input is now a String, e.g. "25" — not the number 25!

2.3 Converting Text to Numbers

The computer cannot do maths with text. "25" - 2026 makes no sense to it. We must convert the string to a number before calculating:

String yearText = sc.nextLine();
int birthYear = Integer.parseInt(yearText);    // text "1998" → number 1998

String tempText = sc.nextLine();
double celsius = Double.parseDouble(tempText);  // text "25.5" → number 25.5

You can also combine reading and converting in one line:

int age = Integer.parseInt(sc.nextLine());
double price = Double.parseDouble(sc.nextLine());

2.3.1 Parse vs Convert — Two Common Styles

Both of these turn text into numbers. You will see both in tutorials and exam answers:

String text = sc.nextLine();

// Style A — Integer.parseInt / Double.parseDouble (used throughout this lesson)
int n1 = Integer.parseInt(text);
double d1 = Double.parseDouble(text);

// Style B — Scanner nextInt / nextDouble (reads the next token as a number)
// int n2 = sc.nextInt();
// double d2 = sc.nextDouble();
// Tip: after nextInt/nextDouble, call sc.nextLine() to clear the leftover newline
Which should you use?

Either is fine for this module. Stick to one style in a program for consistency. Both crash with a NumberFormatException if the text is not a valid number (e.g. "abc"). Later you will meet try/catch with Integer.parseInt for safer validation.

Figure 3.1a — Keyboard input is always a string first. Parsing/converting is the bridge to numeric PROCESS boxes.
Watch Out

If the user types abc when a number is expected, Integer.parseInt crashes the program with a NumberFormatException. For now, always type valid numbers when testing. We will learn safer conversion methods later.

2.4 Mixing Text and Values — Concatenation & format

Instead of joining strings with +, use + to join parts, or String.format and place variables inside { }:

// Joining with + (always works)
System.out.println("Hello " + name + "! You are " + age + " years old.");

// String.format (useful for decimals and alignment)
System.out.println(String.format("Hello %s! You are %d years old.", name, age));

You can put expressions inside the braces too:

System.out.println("Next year you will be " + (age + 1) + ".");

3. Complete Example — Age Calculator

This program asks the user for their name and birth year, then calculates their approximate age. It uses all three flowchart shapes: INPUT, PROCESS, OUTPUT — inside the program skeleton from Sessions 01 and 02.

import java.util.Scanner;

public class AgeCalculator
{
    public static void main(String[] args)
    {
        Scanner sc = new Scanner(System.in);

        // ---------- INPUT ----------
        System.out.print("Enter your name: ");        // print (no ln) keeps cursor on same line
        String name = sc.nextLine();                  // nextLine reads what the user types as TEXT

        System.out.print("Enter your birth year: ");
        String yearText = sc.nextLine();              // Everything typed comes in as a String...

        int birthYear = Integer.parseInt(yearText);   // ...so we PARSE the text to a whole number

        // ---------- PROCESS ----------
        int currentYear = 2026;
        int age = currentYear - birthYear;            // Simple arithmetic, exactly like your flowchart

        // ---------- OUTPUT ----------
        System.out.println("Hello " + name + "! You are about " + age + " years old.");
    }
}
🧠 Beginner's Logic Breakdown
  1. INPUT boxes: sc.nextLine() is your flowchart's INPUT parallelogram. Important: it always gives back text (a String), even if the user types digits.
  2. The conversion step: real computers cannot do maths with text. Integer.parseInt(...) transforms the text "1998" into the number 1998. This is an extra step your flowcharts never needed — but every real program needs it.
  3. PROCESS box: int age = currentYear - birthYear; is a direct translation of your flowchart's process rectangle.
  4. OUTPUT box: System.out.println("Hello " + name + "! You are about " + age + " years old."); — use + to mix fixed text with variable values.
  5. Order matters: lines run top to bottom, exactly like following flowchart arrows.

Session 03 Summary

  • Every variable has a type: int, double, String, boolean, char.
  • Declaration pattern: type name = value;
  • System.out.print for prompts; System.out.println for results.
  • sc.nextLine() always returns a String; use Integer.parseInt / Double.parseDouble before maths.
  • Concatenation "..." + variable and String.format mix text and values cleanly.
  • A complete program = INPUT (Scanner) → PROCESS (calculations) → OUTPUT (println) inside main.
