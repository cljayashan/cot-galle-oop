1. From Flowchart Loop Symbols to Java Loops

In flowcharts you used two loop shapes: the pre-test loop (check condition before entering) and the post-test loop (run the body at least once, then check). Java gives you three loop keywords — each maps to a flowchart pattern you already know.

Figure 6.1 — while = test-then-repeat. do-while = repeat-then-test (at least once). for = counter loop with init, test and update bundled together.
Java LoopFlowchart EquivalentRuns at Least Once?Best For
while (condition)Pre-test loopNo — may skip entirelyUnknown repetitions (input validation)
do { } while (condition);Post-test loopYes — always runs onceMenus ("show menu, then ask again?")
for (init; test; update)Counter-controlled loopDepends on init/testKnown count (1 to N, table rows)

2. Example — Sum of 1 to N (for loop)

Classic counter problem: add every whole number from 1 up to N. The flowchart uses a counter variable i that starts at 1, adds to a running total, increments, and loops while i <= N.

import java.util.Scanner;

public class SumOneToN
{
    public static void main(String[] args)
    {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter N: ");
        int n = Integer.parseInt(sc.nextLine());

        int sum = 0;   // accumulator — holds the running total (starts at zero)

        // for loop = init; condition; update
        //   init:   int i = 1        — start counter at 1
        //   test:   i <= n          — keep going while i is at most n
        //   update: i++             — add 1 to i after each iteration (same as i = i + 1)
        for (int i = 1; i <= n; i++)
        {
            sum = sum + i;         // add current i to the running total
            // System.out.println("Adding " + i + ", sum so far = " + sum);  // uncomment to trace
        }

        System.out.println("Sum of 1 to " + n + " = " + sum);
    }
}
🧠 Beginner's Logic Breakdown — Sum 1 to N
  1. Accumulator pattern: sum = 0 before the loop; inside the loop sum = sum + i. The variable "accumulates" values across iterations — a pattern you will use constantly.
  2. Loop variable i: declared inside the for header (int i = 1). It only exists inside the loop — a good habit that prevents accidental reuse.
  3. i++: shorthand for "increment i by 1". Runs at the end of each iteration, before the condition is checked again.
  4. Trace with N=4: i=1 → sum=1; i=2 → sum=3; i=3 → sum=6; i=4 → sum=10; i=5 fails test → exit. Output: 10.

3. Example — Multiplication Table (for loop nested concept)

Print the 5-times table from 1 to 12. One loop; each iteration prints one line.

public class MultiplicationTable
{
    public static void main(String[] args)
    {
        int number = 5;

        System.out.println("=== Multiplication Table for " + number + " ===");

        for (int i = 1; i <= 12; i++)
        {
            int product = number * i;   // PROCESS box inside the loop
            System.out.println(number + " x " + i + " = " + product);
        }
    }
}
Generalising the Table

Ask the user which number's table they want (Integer.parseInt(sc.nextLine())), store it in number, and the same loop works for any value. That is the power of variables over hard-coded numbers.

4. Example — Input Validation Loop (while)

Sometimes you must keep asking until the user gives valid input. A while loop repeats while the input is bad — the flowchart pre-test diamond at the top.

import java.util.Scanner;

public class InputValidation
{
    public static void main(String[] args)
    {
        Scanner sc = new Scanner(System.in);
        int age = -1;   // sentinel value — anything invalid to start the loop

        // Keep asking WHILE age is not in the valid range
        while (age < 0 || age > 120)
        {
            System.out.print("Enter your age (0-120): ");
            age = Integer.parseInt(sc.nextLine());

            if (age < 0 || age > 120)
            {
                System.out.println("Invalid! Age must be between 0 and 120.");
            }
        }

        System.out.println("Thank you. Age recorded: " + age);
    }
}

4.1 do-while — At Least One Attempt

The same validation with do-while: the body runs once before the first test — useful when you always want to prompt at least once.

int age;
do
{
    System.out.print("Enter your age (0-120): ");
    age = Integer.parseInt(sc.nextLine());
    if (age < 0 || age > 120)
        System.out.println("Invalid! Try again.");
} while (age < 0 || age > 120);   // note the semicolon after while (...)

5. break and continue — Controlling Loop Flow

KeywordEffectFlowchart Analogy
break;Immediately exits the entire loopArrow jumping out of the loop back to code after it
continue;Skips the rest of this iteration; goes to next testArrow skipping remaining boxes and going back to the diamond
 
// Print 1 to 10 but STOP at 7 (break)
for (int i = 1; i <= 10; i++)
{
    if (i == 7)
        break;                    // exit the for loop entirely
    System.out.println(i);
}
// Output: 1 2 3 4 5 6

// Print 1 to 10 but SKIP 5 (continue)
for (int i = 1; i <= 10; i++)
{
    if (i == 5)
        continue;                 // skip System.out.println for this i only
    System.out.println(i);
}
// Output: 1 2 3 4 6 7 8 9 10
Infinite Loops

If the loop condition never becomes false, the loop runs forever. Example: while (true) without a break inside. Always ensure something inside the loop eventually makes the condition false — or use break deliberately (common in menu systems; Session 07).

6. Lab Tasks & Exam Practice

🔬 Lab Task 6.1 — Factorial Calculator (60 min)

Create a Java Application called FactorialCalc. Factorial of N (written N!) = 1 × 2 × 3 × ... × N. Example: 5! = 120.

  1. Read a non-negative integer N from the user.
  2. Use a for loop to multiply numbers 1 through N into an accumulator called factorial (start at 1, not 0 — why?).
  3. Print: 5! = 120.
  4. Challenge: if N < 0, print an error and do not loop. If N == 0, print 0! = 1 (by definition).

Hint: accumulator pattern — but multiply instead of add: factorial = factorial * i.

🔬 Lab Task 6.2 — Number Guessing Game (75 min)

Create a Java Application called GuessTheNumber. The computer picks a secret number (hard-code int secret = 42; for now). The player keeps guessing until correct.

  1. Use a while loop: continue while the guess is not equal to secret.
  2. Each iteration: read a guess, print "Too high", "Too low", or "Correct!" (combine loop + if from Session 05).
  3. Count how many guesses it took; print the count when they win.
  4. Challenge: use Random rnd = new Random(); int secret = rnd.Next(1, 101); for a random number 1–100. Limit to 7 guesses; use break if they run out.

Session 06 Summary

  • while = pre-test loop; may run zero times. do-while = post-test; runs at least once.
  • for (init; test; update) bundles counter logic — ideal when you know how many repetitions.
  • Accumulator pattern: initialise (sum = 0 or product = 1), update inside loop.
  • break exits the loop; continue skips to the next iteration.
  • Loops + if statements = interactive programs (validation, guessing games, menus).
