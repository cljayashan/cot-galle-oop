Variable Scope — Who Can See This Variable?

A short, simple lesson: every variable lives in a “room.” Outside that room, the name does not exist. Learn the three rooms students meet most often — class fields, method parameters, and local variables.

⏱ ~2 Hours Integrated 📋 Session A2.1 🟢 Beginner-friendly

Learning Outcomes — After this lesson you will be able to:

  • Explain what “scope” means in plain English
  • Tell apart a field, a parameter, and a local variable
  • Predict whether a name is visible inside or outside a method / block
  • Use this when a parameter hides a field with the same name

Quick Map

KindWhere declaredWho can use it
FieldInside the class, outside methodsAny method of that object
ParameterIn the method’s ( … )Only that method
Local variableInside a method or { } blockOnly from that point to the end of the block

Lesson A2 Summary

  • Scope = the area of code where a name is known.
  • Fields live with the object; locals die when the method ends.
  • Same name in two places? The inner one “wins” (shadowing) — use this.field for the field.
