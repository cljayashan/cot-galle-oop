Question 7 — Write a complete program (6 marks)
Model answer (equivalent accepted):
import java.util.Scanner; public class StudentCard { public static void main(String[] args) { Scanner sc = new Scanner(System.in); String name = sc.nextLine(); int mark = Integer.parseInt(sc.nextLine()); // accept: int mark = sc.nextInt(); System.out.println("Student: " + name + " | Mark: " + mark); } }
CriteriaMark
Correct class name StudentCard and valid main method structure1
Required import java.util.Scanner; (or fully-qualified use of Scanner)1
Creates Scanner reading from System.in1
Reads name into a String variable1
Reads mark into an int (accept nextInt() or parseInt(nextLine()))1
Prints in the required form: Student: ... | Mark: ...1

Do not heavily penalize missing braces style or indentation if the program is logically correct. Package line is optional.
