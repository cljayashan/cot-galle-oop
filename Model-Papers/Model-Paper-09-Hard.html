Question 1  [20 Marks]

Design under constraints.

  1. Design a Course registration helper: course code, capacity, enrolled count. Enforce capacity with exceptions. (8 marks)
  2. Implement enrol/drop methods with full validation. (8 marks)
  3. Discuss whether capacity checks belong in the UI, the domain class, or both. (4 marks)
Question 2  [20 Marks]

Strategy via interfaces.

  1. Create interface DiscountPolicy with double apply(double price). (4 marks)
  2. Implement NoDiscount, PercentOff, and StudentDiscount. (9 marks)
  3. Write class Cart that holds a policy and a price, and show switching policies without changing Cart's core code. (7 marks)
Question 3  [20 Marks]
class Box { int n; Box(int n) { this.n = n; } void add(Box other) { this.n += other.n; } } // main: Box x = new Box(5); Box y = x; Box z = new Box(5); y.add(z); System.out.println(x.n + " " + y.n + " " + z.n); z = y; z.n = 1; System.out.println(x.n + " " + y.n + " " + z.n);

Harder trace.

  1. Give both lines of output. (8 marks)
  2. Explain aliasing after Box y = x and after z = y. (8 marks)
  3. If add did other = new Box(0) inside the method, would z in main change? Why? (4 marks)
Question 4  [20 Marks]

Abstract factory-lite (manual).

  1. Define abstract Notification with deliver() and concrete Email/SMS types. (8 marks)
  2. Write a method Notification create(String type) that returns the right subclass (or throws on unknown type). (8 marks)
  3. Explain how this supports open/closed thinking at beginner level. (4 marks)
Question 5  [20 Marks]

School system consistency.

  1. Model Teacher, Classroom, and Student with a mix of association and composition - justify each link. (8 marks)
  2. Implement enough Java to add a student to a classroom and list names. (8 marks)
  3. What invariant should the model protect (e.g. student not in two seats)? How? (4 marks)
Question 6  [20 Marks]

Error-handling architecture.

  1. Design a layered approach: domain throws, menu catches, logs a simple message. Illustrate with code sketches. (10 marks)
  2. Should main catch Exception broadly? Argue for or against for this module's apps. (6 marks)
  3. Name two unchecked and one checked exception category example (theory). (4 marks)
Question 7  [20 Marks]
class Bad { public int[] marks = new int[3]; public String name; public double avg() { return (marks[0]+marks[1]+marks[2])/3.0; } }

Refactoring challenge.

  1. List four concrete problems in Bad (encapsulation, validation, API, misuse). (8 marks)
  2. Produce an improved class API and implementation. (8 marks)
  3. Show how client code must change and why that is healthier long-term. (4 marks)
