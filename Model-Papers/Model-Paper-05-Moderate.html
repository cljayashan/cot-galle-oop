Question 1  [20 Marks]

Building an inheritance tree.

  1. Write class Person with private name, a constructor, and getName(). (6 marks)
  2. Write class Teacher extends Person with private subject, constructor calling super, and display(). (10 marks)
  3. Explain what super(name) does in the subclass constructor. (4 marks)
Question 2  [20 Marks]

Protected access.

  1. How does protected differ from private and public? (6 marks)
  2. Give a short example where a subclass method reads a protected superclass field. (8 marks)
  3. When would you still prefer private fields + getters over protected fields? (6 marks)
Question 3  [20 Marks]

Method overriding.

  1. What is overriding? How is it different from overloading? (6 marks)
  2. Write superclass method speak() and a subclass override that prints a different message. Include @Override. (8 marks)
  3. What is printed by Animal a = new Dog(); a.speak(); if Dog overrides speak? Why? (6 marks)
Question 4  [20 Marks]

Polymorphism - first ideas.

  1. Define polymorphism in the context of OOP. (4 marks)
  2. Explain why a list of Vehicle references can hold Car and Bike objects. (6 marks)
  3. Write a small demo: array or list of superclass type, two subclasses, loop calling an overridden method. (10 marks)
Question 5  [20 Marks]
class Shape { public double area() { return 0; } } class Circle extends Shape { private double r; public Circle(double r) { this.r = r; } public double area() { return 3.14 * r * r; } }

Study the code.

  1. Identify the superclass, subclass, and overridden method. (6 marks)
  2. What does Shape s = new Circle(2); System.out.println(s.area()); print (approx)? (4 marks)
  3. Rewrite Shape.area as abstract and make Shape an abstract class. Adjust Circle if needed. (10 marks)
Question 6  [20 Marks]

Library Phase 4/5 style thinking.

  1. Suggest a superclass for different library items (book, DVD) and two subclasses with one extra field each. (8 marks)
  2. Which behaviours belong in the superclass and which in subclasses? Justify briefly. (6 marks)
  3. How does inheritance reduce duplicated code in borrow/return logic? (6 marks)
Question 7  [20 Marks]

Exceptions - awareness (additional topic).

  1. What is an exception? What happens if it is not caught? (4 marks)
  2. Write a try/catch around Integer.parseInt that prints a friendly message on failure. (8 marks)
  3. Name three common exception types and one cause for each. (6 marks)
  4. Why is checking if (obj != null) often better than catching NullPointerException? (2 marks)
