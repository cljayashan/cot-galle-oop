Question 1  [20 Marks]

This question covers JDK tools and the structure of a simple Java program.

  1. What do the abbreviations JDK and JVM stand for? State one role of each. (6 marks)
  2. Name the IDE allowed in this module and the extension pack needed for Java. (4 marks)
  3. Write the two terminal commands to compile and run a file named Hello.java (class Hello). (4 marks)
  4. Why must the main method be present in a console application? (6 marks)
Question 2  [20 Marks]

Data types and console output.

  1. List five primitive Java types used in this module and give one example value for each. (5 marks)
  2. Write declarations (with initial values) for: student name, age, course fee, paid status, and grade letter. (5 marks)
  3. Write one System.out.println statement that prints: Hello Amal, age 21 using variables name and age. (4 marks)
  4. Explain the difference between String quotes and char quotes with one example each. (6 marks)
Question 3  [20 Marks]
int marks = 65; if (marks >= 50) { System.out.println("Pass"); } else { System.out.println("Fail"); }

Study the decision structure below.

  1. What is printed when marks is 65? What is printed when marks is 40? (4 marks)
  2. Rewrite the program using an if / else if / else chain that prints Distinction (>=75), Credit (65-74), Pass (50-64), or Fail. (10 marks)
  3. Explain in one sentence when the else block runs. (6 marks)
Question 4  [20 Marks]

Loops - basics.

  1. Write a for loop that prints the numbers 1 to 5 (each on a new line). (6 marks)
  2. Write a while loop that prints "Hello" exactly three times. (6 marks)
  3. State one difference between while and do-while. (4 marks)
  4. Why can an infinite loop be a problem in a console menu? (4 marks)
Question 5  [20 Marks]

Methods - simple reuse.

  1. What does the keyword void mean in a method header? (4 marks)
  2. Write a method public static void greet(String name) that prints Welcome, <name>. (6 marks)
  3. Write a method public static int square(int n) that returns n * n. Show one call from main. (6 marks)
  4. Explain the difference between a parameter and an argument. (4 marks)
Question 6  [20 Marks]

Classes and objects - first look.

  1. In one sentence each, define class and object. (6 marks)
  2. Write a class Book with two public fields: title (String) and pages (int). (6 marks)
  3. In main, create one Book object, set both fields, and print them. (6 marks)
  4. Why can many objects be created from the same class? (2 marks)
Question 7  [20 Marks]

Encapsulation - introductory idea.

  1. What does encapsulation mean in simple words? Give one real-world analogy (e.g. ATM). (6 marks)
  2. Why is a public balance field dangerous in a bank account class? (6 marks)
  3. Write a private field balance and a public method getBalance() that returns it. (6 marks)
  4. What access modifier means "visible only inside the same class"? (2 marks)
