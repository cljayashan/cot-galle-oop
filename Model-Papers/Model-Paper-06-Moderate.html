Question 1  [20 Marks]

Abstract classes.

  1. What is an abstract class? Can you write new AbstractType() if the type is abstract? (6 marks)
  2. Write abstract class Employee with an abstract method pay() and a concrete method getName(). (8 marks)
  3. Write one concrete subclass that implements pay(). (6 marks)
Question 2  [20 Marks]

Interfaces.

  1. What is an interface in Java? How does a class use one? (6 marks)
  2. Write interface Payable with method double amountDue() and a class that implements it. (8 marks)
  3. State two differences between an abstract class and an interface (as taught for this level). (6 marks)
Question 3  [20 Marks]

Association, aggregation, composition - concepts.

  1. Explain association (uses-a) with a short Java-flavoured example. (6 marks)
  2. Explain aggregation (has-a, shared lifetime) vs composition (part-of, strong ownership) with school/classroom examples. (10 marks)
  3. Why does composition often create the part objects inside the whole's constructor? (4 marks)
Question 4  [20 Marks]

School project style.

  1. Design classes Teacher and Classroom showing a clear relationship (state which relationship you chose). (6 marks)
  2. Write Java outlines (fields + constructors + one method each) for your design. (10 marks)
  3. How would you print all students in a classroom if the classroom aggregates a list of students? (4 marks)
Question 5  [20 Marks]

Combining encapsulation + inheritance.

  1. Write Account with private balance, protected deposit helper or public deposit, and abstract calcInterest(). (10 marks)
  2. Write SavingsAccount that extends it and implements interest calculation. (6 marks)
  3. Explain how encapsulation still protects balance while inheritance reuses behaviour. (4 marks)
Question 6  [20 Marks]
interface Notifier { void send(String msg); } class EmailNotifier implements Notifier { public void send(String msg) { System.out.println("EMAIL: " + msg); } }

Study the interface example.

  1. What must every implementing class provide? (4 marks)
  2. Write a SmsNotifier implementation. (6 marks)
  3. Write a method alert(Notifier n, String m) that calls n.send(m), and show calls with both implementations. (10 marks)
Question 7  [20 Marks]

Garbage collection & lifecycle (link to memory lesson).

  1. Describe birth, life, and abandonment of an object in heap terms. (6 marks)
  2. What is the Garbage Collector's job? Do you call delete in Java? (6 marks)
  3. Show code that makes an object unreachable (e.g. assign null or reassign the only reference). (4 marks)
  4. Why can large temporary objects in a loop cause memory pressure even with GC? (4 marks)
