Question 1  [20 Marks]

Full encapsulation review.

  1. Critique a class that exposes public arrays of marks - what can go wrong? (6 marks)
  2. Redesign with private data, controlled addMark/getAverage, and validation 0-100. (10 marks)
  3. Write a short note on information hiding for a non-technical manager. (4 marks)
Question 2  [20 Marks]

Multi-level inheritance care.

  1. Write inheritance chain Vehicle -> Car -> ElectricCar with one new field/method at each level. (10 marks)
  2. Show constructor chaining with super at each level. (6 marks)
  3. State one risk of deep inheritance trees and one alternative (e.g. composition). (4 marks)
Question 3  [20 Marks]

Interface segregation lite.

  1. Define interfaces Borrowable and Reservable with suitable methods. (6 marks)
  2. Implement a Book that is borrowable and reservable, and a Magazine that is only borrowable. (10 marks)
  3. Why might two small interfaces be better than one large "LibraryItemOps" interface? (4 marks)
Question 4  [20 Marks]

Polymorphic collections.

  1. Create an abstract Staff with work(); concrete Librarian and Clerk. (8 marks)
  2. Store both in a List<Staff> (or array) and invoke work() in a loop. (6 marks)
  3. Explain what would break if work were removed from the superclass and only defined in subclasses while the list type stayed Staff. (6 marks)
Question 5  [20 Marks]

Classroom composition.

  1. Write Desk and a Classroom that owns a fixed array/list of desks created in its constructor. (10 marks)
  2. Add occupyDesk(int index, String studentName) with bounds checks. (6 marks)
  3. Why is this composition rather than a weak association? (4 marks)
Question 6  [20 Marks]
class A { void hello() { System.out.println("A"); } } class B extends A { void hello() { System.out.println("B"); } void onlyB() { System.out.println("onlyB"); } }

Predict and reason.

  1. For A x = new B(); which calls compile: x.hello(), x.onlyB()? What prints for the legal call? (8 marks)
  2. How can you call onlyB safely using a cast? What risk does a wrong cast bring? (6 marks)
  3. Rewrite using an override-only design so clients need no cast for normal use. (6 marks)
Question 7  [20 Marks]

Exam scenario - COT library desk.

  1. A librarian needs to search by title keyword and borrow by ISBN. Outline classes/methods (no full code). (8 marks)
  2. Write the matchesSearch(String keyword) method body using toLowerCase / contains. (6 marks)
  3. Explain where encapsulation and exceptions would improve this desk system. (6 marks)
