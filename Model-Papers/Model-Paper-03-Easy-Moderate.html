Question 1  [20 Marks]

Class anatomy.

  1. Label each of the following as field, method, or neither: speed, accelerate(), package, brand. (4 marks)
  2. Write a Vehicle class with fields brand and speed, plus methods accelerate() (adds 10 to speed) and display(). (10 marks)
  3. Create two vehicles in main with different brands and show their speeds after one accelerate each. (6 marks)
Question 2  [20 Marks]

Access modifiers.

  1. Explain public vs private with one example each. (6 marks)
  2. What compile-time problem occurs if main tries to write to a private field directly? (4 marks)
  3. Refactor a public field balance into private + getter + deposit method with a positive-amount check. (10 marks)
Question 3  [20 Marks]
public class BankAccount { private double balance; public void deposit(double amount) { if (amount > 0) balance += amount; } }

Study the fragment.

  1. Why can deposit change balance even though the field is private? (4 marks)
  2. Add withdraw(double amount) that refuses negative amounts and amounts greater than balance. (8 marks)
  3. Add getBalance() and show three calls from main: deposit, withdraw, print. (8 marks)
Question 4  [20 Marks]

Constructors - introduction.

  1. What is a constructor? How does its name relate to the class name? (4 marks)
  2. Does a constructor have a return type (including void)? Explain. (4 marks)
  3. Write a default constructor and a parameterized constructor for class Product with fields name and price. (8 marks)
  4. When does a constructor run? (4 marks)
Question 5  [20 Marks]

The keyword this (simple).

  1. What does this refer to inside an instance method? (4 marks)
  2. Write setPrice(double price) { this.price = price; } and explain each price. (8 marks)
  3. What problem appears if you write price = price; inside that setter? (4 marks)
  4. Give one other situation where this is useful. (4 marks)
Question 6  [20 Marks]

Rectangle: procedural vs object (bridge).

  1. Describe how a procedural Rectangle program stores width and height. (4 marks)
  2. Write an OO Rectangle with private fields, a constructor, area(), and perimeter(). (10 marks)
  3. State two benefits of the OO version for a program that needs many rectangles. (6 marks)
Question 7  [20 Marks]

Library Phase 1 style - Book.

  1. List suitable fields for a library Book (at least four). (4 marks)
  2. Write borrow() and returnBook() methods that prevent double-borrow / double-return using a boolean flag. (10 marks)
  3. Explain why availability should not be set freely from outside without rules. (6 marks)
