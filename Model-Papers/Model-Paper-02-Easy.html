Question 1  [20 Marks]

Console input with Scanner.

  1. Write the import and the line that creates a Scanner reading from System.in. (4 marks)
  2. Write code that asks for a student's name and age, reads both, and prints them. (8 marks)
  3. Which method reads a whole line of text? Which is commonly used for an int? (4 marks)
  4. What problem can occur if the user types letters when an integer is expected? (Name the issue in plain words.) (4 marks)
Question 2  [20 Marks]

Operators and expressions.

  1. Evaluate: 10 + 3 * 2 and (10 + 3) * 2. Show working. (4 marks)
  2. Write a boolean expression that is true when age is at least 18 and hasId is true. (4 marks)
  3. Explain the difference between = and == with a tiny example. (6 marks)
  4. What does the modulus operator % return? Give one example. (6 marks)
Question 3  [20 Marks]
public static int add(int a, int b) { return a + b; }

Study the method.

  1. What are the return type and the two parameters? (4 marks)
  2. Write a complete main that calls add(7, 5) and prints the result. (6 marks)
  3. Rewrite the method as void so it prints the sum instead of returning it. (6 marks)
  4. Can a void method use return 5;? Explain briefly. (4 marks)
Question 4  [20 Marks]

Fields vs local variables (simple).

  1. Where is a field declared? Where is a local variable declared? (6 marks)
  2. Write a class Lamp with a field boolean isOn and methods turnOn() / turnOff() that change it. (8 marks)
  3. Explain why a local variable declared inside turnOn cannot be used inside turnOff. (6 marks)
Question 5  [20 Marks]

Getters and setters - first practice.

  1. What is a getter used for? What is a setter used for? (4 marks)
  2. For a private field String title, write getTitle and setTitle. (8 marks)
  3. Improve setTitle so it rejects an empty string (print a message and keep the old value). (6 marks)
  4. State the usual JavaBeans name for a getter of field author. (2 marks)
Question 6  [20 Marks]

Procedural vs OOP (simple comparison).

  1. Describe procedural programming in two sentences. (4 marks)
  2. Describe object-oriented programming in two sentences. (4 marks)
  3. Name the four pillars of OOP. (4 marks)
  4. Give one advantage of modelling a library with Book objects instead of only separate variables in main. (8 marks)
Question 7  [20 Marks]

Simple class design.

  1. Using the noun/verb idea, list two fields and two methods for a Student class. (6 marks)
  2. Write the Java class with those private fields and public methods (stubs are enough for methods that only print). (10 marks)
  3. In main, create two different Student objects to show that each has its own data. (4 marks)
