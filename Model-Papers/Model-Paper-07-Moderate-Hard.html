Question 1  [20 Marks]

Design a mini inventory.

  1. Specify fields and methods for Item (code, name, qty) with encapsulation rules. (6 marks)
  2. Implement the class with constructor, getters, restock, and issue (issue must not make qty negative). (10 marks)
  3. Explain how you would unit-test issue manually from main with two scenarios. (4 marks)
Question 2  [20 Marks]

Inheritance + overriding under rules.

  1. Create Ticket with method price() returning a base amount. (4 marks)
  2. Create StudentTicket and VipTicket with different price rules via override. (10 marks)
  3. Demonstrate polymorphic pricing in a loop over a Ticket[]. (6 marks)
Question 3  [20 Marks]

throw for domain rules.

  1. Rewrite a setter or withdraw method so invalid input throws IllegalArgumentException. (8 marks)
  2. Catch the exception in main and keep a menu running. (8 marks)
  3. Compare throwing vs printing an error message inside the class - when is throwing better? (4 marks)
Question 4  [20 Marks]
class Node { int value; Node next; } public class Trace { public static void main(String[] args) { Node a = new Node(); a.value = 1; Node b = a; b.value = 2; System.out.println(a.value); b = new Node(); b.value = 3; System.out.println(a.value); } }

Trace and fix.

  1. What is printed by each println? Explain with stack/heap reasoning. (10 marks)
  2. Draw (or describe) references after b = new Node(). (6 marks)
  3. What would a.next.value do if a.next was never set? (4 marks)
Question 5  [20 Marks]

Abstract reporting.

  1. Design abstract Report with abstract generate() and concrete header(). (8 marks)
  2. Implement SalesReport and AttendanceReport. (8 marks)
  3. Show how a method can accept Report r and call generate without knowing the concrete type. (4 marks)
Question 6  [20 Marks]

Composition deep dive.

  1. Model a Computer composed of Cpu and Memory (composition). Write constructors that create the parts inside Computer. (10 marks)
  2. Explain why deleting/losing the Computer reference means the parts are no longer needed by the program. (4 marks)
  3. How would the design change if Memory could be swapped and reused in another computer (aggregation)? (6 marks)
Question 7  [20 Marks]

Safe console menu (integration).

  1. Write a helper readInt(Scanner sc) that loops until a valid integer is entered (use try/catch). (8 marks)
  2. Build a 3-option menu that uses the helper and exits cleanly on option 0. (8 marks)
  3. State two user mistakes your menu now survives. (4 marks)
