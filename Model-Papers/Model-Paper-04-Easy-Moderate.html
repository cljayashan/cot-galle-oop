Question 1  [20 Marks]

Design rule: hide data.

  1. State the usual rule for fields vs methods regarding public/private. (4 marks)
  2. Write an encapsulated Employee with private name and salary, getters, and a setter for salary that rejects values below 0. (10 marks)
  3. Show illegal vs legal access from main (one illegal line commented with the reason). (6 marks)
Question 2  [20 Marks]

Method overloading (same name, different parameters).

  1. What is method overloading? (4 marks)
  2. Write three overloaded print methods: one for int, one for String, one for int and String. (9 marks)
  3. How does Java decide which overloaded method to call? (4 marks)
  4. Can two methods overload if they differ only by return type? Explain. (3 marks)
Question 3  [20 Marks]

Constructor overloading.

  1. Write class Member with fields id and name, a no-arg constructor (default values), and a two-arg constructor. (10 marks)
  2. In main, create one object with each constructor and print their data. (6 marks)
  3. What does Java provide if you write no constructor at all? (4 marks)
Question 4  [20 Marks]

Stack vs heap (simple memory).

  1. In simple words, what lives on the stack and what lives on the heap? (6 marks)
  2. Explain why Book a = b; can make two variables affect the same book. (8 marks)
  3. What does null mean? What exception appears if you call a method on null? (6 marks)
Question 5  [20 Marks]

Inheritance vocabulary.

  1. Define inheritance and the is-a relationship with one example (e.g. Car / Vehicle). (6 marks)
  2. Which keyword creates an inheritance link in Java? Write one class header example. (4 marks)
  3. Who is the superclass and who is the subclass in class Dog extends Animal? (4 marks)
  4. Can a subclass use private fields of the superclass directly? How should it access them? (6 marks)
Question 6  [20 Marks]

Variable scope (simplified).

  1. Define scope in one sentence. (3 marks)
  2. Classify count (field), value (parameter), and next (declared inside a method) by scope. (6 marks)
  3. Why does a variable declared inside an if block fail to compile if used after the block? (5 marks)
  4. Write a tiny example that needs this.x = x; and explain why. (6 marks)
